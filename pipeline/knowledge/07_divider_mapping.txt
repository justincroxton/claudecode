GLOBAL DIVIDER FORMATTING RULES (APPLIES TO ALL DIVIDERS)
==========================================================

- Page size: 8.5 x 11 inches (US Letter)
- Position: x-axis 0, y-axis 0 (top-left corner of page)
- Sizing: Fit to page (full bleed - 612pt x 792pt at 72 DPI,
  or 8.5" x 11" exact)
- Image wrapping: Behind text (BEHIND_DOCUMENT) for text-overlay dividers
- Image wrapping: In line with text (full page, no wrap) for static dividers
- Page break: Both before AND after every divider so it occupies
  its own page

TWO TYPES OF DIVIDERS
======================

TYPE 1 - STATIC DIVIDERS (most common)
  - Filename does NOT contain "text_overlay"
  - Image renders full-page in-line
  - No text rendered on top
  - Use ImageRun with full-page transformation

TYPE 2 - TEXT-OVERLAY DIVIDERS (special)
  - Filename CONTAINS "text_overlay"
  - Image renders behind document (BEHIND_DOCUMENT wrap)
  - Dynamic text renders ON TOP of image with absolute positioning
  - Use ImageRun with floating positioning + text frames over it
  - Text content varies per RFP (institution name, RFP title, etc.)

FRONT MATTER DIVIDERS (AA-AD) - APPEAR BEFORE COVER LETTER
==================================================================

These four dividers form the proposal opening sequence in this order:

ORDER 1: divider_AA_Page_Cover_text_overlay.jpg [TEXT OVERLAY]
  -> Title Page / Cover Page
  -> TEXT TO OVERLAY (rendered dynamically per RFP):
     - Line 1: [Institution Name] (large, bold, brand red)
     - Line 2: [RFP Title or RFP Number] (medium, white)
     - Line 3: Submitted: [Submission Date] (small, white)
     - Line 4: Submitted by: Propellant Media (small, white)
  -> Position text in lower-left or upper-center area where image
     has empty negative space designed for it

ORDER 2: divider_AB_academic_logos.jpg [STATIC]
  -> Academic Client Logos page
  -> No text overlay - image is complete as-is
  -> Renders immediately after Title Page

ORDER 3: divider_AC_Growing_enrollment_page_text_overlay.jpg [TEXT OVERLAY]
  -> Propellant Media Positioning / Value Prop page
  -> TEXT TO OVERLAY (generic Propellant Media positioning -
     same text every RFP):
     - Headline: "Growing Enrollment for Forward-Thinking Institutions"
     - Subhead/body copy: Propellant Media positioning statement
       (3-4 sentences) about MWBE certification, Google Premier
       status, higher education focus, AI-powered enrollment
       marketing capabilities
  -> Standard text - skill writes this same content for every RFP

ORDER 4: divider_AD_Table_Of_Contents_text_overlay.jpg [TEXT OVERLAY]
  -> Table of Contents
  -> TEXT TO OVERLAY (dynamic per RFP):
     - "Table of Contents" header
     - Full TOC entries with section titles + page numbers + dot leaders
     - Generated from final document structure
  -> Note: TOC text overlays directly on the image. The image is
     the design treatment; the TOC content sits on top.

SECTION ORDER NOTES
===================

The order above follows the v7 template's Standard Section Order
(Mode B - default when RFP is silent on structure).

When an RFP prescribes a different order (Mode A) or names required
sections without mandating full structure (Mode C):
  - Match dividers by section CONTENT, not by number
  - The rfp-engine skill will identify the closest matching divider
    based on section topic
  - If no clear match exists, use divider_21_sample_divider_placeholder.png
  - Front matter dividers (AA-AD) ALWAYS appear in this order
    regardless of TOC mode

SECTIONS WITHOUT DEDICATED DIVIDERS
====================================

The following standard v7 sections do NOT have dedicated dividers
because they are typically integrated into other sections or do not
warrant a full-page divider:

use divider_21_sample_divider_placeholder.png and flag for
